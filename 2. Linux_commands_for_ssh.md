# 🔑 SSH en Linux

---

For this funny project you need 2 machines with linux. In my case: I have a laptop with fedora and a computer running kali linux in vmware

By default, most Linux distributions already have OpenSSH installed, but we must ensure that the service is active and the firewall allows it.

Remember the following:
- Server: The Linux machine that will act as the server (we will open the SSH port here).

- Client: The Linux machine that will act as the client (we will connect to the server from this machine).

---

## **STEP 1:** Set up the SSH server in the **server machine**

**1. Open the terminal and install OpenSSH:**
```
# For RHEL-based (Fedora, CentOS Stream, RHEL, Rocky Linux, AlmaLinux)
sudo dnf update && sudo dnf install openssh-server -y

# For Debian-based (Ubuntu, Debian, Linux Mint, Pop!_OS)
sudo apt update && sudo apt install openssh-server -y
```
**2. Start the ssh service**
```
sudo systemctl start sshd
```
If you want to start the ssh server everytime you reboot your machine:
```
sudo systemctl enable --now sshd
```
- `enable`: Tells systemd to hook this service into the system startup sequence so it auto-starts on future reboots.
- `--now`: Forces `systemctl` to start the service right now in addition to enabling it for boot.
**3. Allow SSH traffic through the Fedora firewall:**
```
sudo firewall-cmd --add-service=ssh --permanent
sudo firewall-cmd --reload
```
**4. Get the local ip:** Enter the follow command and look for something like this: `inet xx.xx.xx.xx/xx ...`
```
ip a
```
Let's say the IP is `192.168.18.168`
You also need to know your user. You can know it just typing `whoami` in the terminal. Let's say, our user is `Fabric047`

---

## **STEP 2:** Go to your **client machine** and do this:

1. Open your terminal and run this command pointing to the server machine:
```
ssh usuario_fedora@192.168.1.X
```
In my case it will be: `ssh Fabric047@192.168.18.168`

You will see a fingerprint warning. Type yes, press Enter and enter the user password of the **server machine**. That'll get you in!
From now on, remember that all commands you execute will affect the server machine, NOT this client machine.

## Now, Let's get funny with this!!!

**1. Monitor processes and hardware in real time:** 
```
sudo dnf install htop -y 
htop
## Use dnf for RHEL-based (like fedora). Otherwise, use 'apt' for Debian-based (like ubuntu)
```

**2. Send a message to the GUI
```
DISPLAY=:0 notify-send "¡Alert!" "I can see you xd"
```

**3. Shut down the server machine
```
sudo shutdown -h now
```

**4. You can do almost everything you would do on your own machine:
Create a script like `nano my_new_script.py` and write something there and execute it with `chmod +x` and then `python3 my_new_script.py`
Move files with `mv file.txt ./new_folder` or remove files with `rm file.txt` or folders with `rm -r ./folder` and so on
